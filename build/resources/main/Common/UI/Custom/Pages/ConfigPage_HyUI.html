Sobre o HorseFollow

This plugin creates a persistent bond between the player and a mount. Supports horses and rams. Binding is done using feed items (Horse Feed / Ram Feed). Once bound, the mount actively follows its owner. Follow distance and teleport behavior are configurable; automatic teleport can be fully disabled.
