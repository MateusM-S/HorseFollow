# Referência Item/Idle (mão direita)

- **Idle.blockyanim** aqui é uma **referência de formato**: mesmos ossos do conjunto vanilla **Item** (R-Arm, R-Forearm, R-Hand), com quaternions espelhados a partir da tocha (L→R) para você se basear.
- Para obter o **Idle vanilla exato** do jogo: execute na pasta `libs/Analise/Item/` o script **ListAndExtractItemIdle.ps1** (com o Hytale instalado e Assets.zip no caminho padrão). Os arquivos extraídos sobrescrevem/ficam junto desta pasta.
- Caminho no Assets.zip: `Common/Characters/Animations/Items/Item/Idle.blockyanim` (ou equivalente).
